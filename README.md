## Deskripsi Singkat Repository
Repository ini merupakan wadah penyimpanan dokumentasi, catatan, dan rangkuman materi dari kegiatan sosialisasi Pengenalan Akademik Jurusan Teknik Informatika dan Komputer (JTIK) Politeknik Negeri Jakarta tahun 2026.

Tujuan repository ini adalah sebagai rekam jejak digital (portofolio) dan referensi pribadi mahasiswa untuk memahami aturan akademik, panduan kedisiplinan, prosedur fasilitas laboratorium, struktur kurikulum, hingga materi teknis penunjang perkuliahan (seperti Git, GitHub, dan pemanfaatan AI) yang berlaku dan digunakan selama masa perkuliahan.

### 2. Catatan dan Rangkuman Materi Workshop

**A. Akademik, Kedisiplinan, dan Fasilitas**
- **Arah Strategis Jurusan:** JTIK memiliki visi menjadi jurusan bertaraf internasional di bidang Informatika dan Komputer dengan fokus pada pendidikan vokasi, riset & inovasi, serta tata kelola digital[cite: 10]. Target jurusan pada tahun 2030 mencakup penyerapan lulusan $\ge 95\%$ dan kepuasan mahasiswa serta mitra $\ge 85\%$[cite: 10].
- **Aturan Penampilan:** Mahasiswa pria diwajibkan memiliki model potongan rambut pendek yang rapi, disisir, tidak menutupi dahi/mata, tidak menutupi telinga, dan bagian belakang tidak melebihi kerah baju[cite: 4]. Rambut panjang yang diikat (man bun) dilarang[cite: 4]. Mahasiswa wajib berpakaian rapi dan menggunakan sepatu tertutup bagian belakang; dilarang menggunakan sepatu sandal, sepatu selop, atau menginjak bagian belakang sepatu[cite: 11].
- **Perilaku di Kampus:** Mahasiswa dilarang keras makan, minum, dan merokok di gedung kuliah, ruang kelas, laboratorium, dan bengkel[cite: 11]. Selain itu, dilarang melakukan kecurangan akademik seperti plagiasi karya ilmiah, mencontek, memalsukan dokumen, dan memalsukan tanda tangan[cite: 11].
- **Prosedur Laboratorium (Berdasarkan Referensi Gambar):**
  * Sesuai file "Alur Peminjaman Alat Laboratorium.png", mahasiswa yang ingin meminjam alat untuk dibawa pulang wajib mengisi Form Peminjaman Alat, meminta persetujuan dan tanda tangan Kepala Laboratorium (Kalab), lalu menyerahkannya kepada teknisi[cite: 1].
  * Sesuai file "Alur Peminjaman Ruangan di Laboratorium.png", mahasiswa harus mengonfirmasi ketersediaan jadwal ke teknisi/admin; jika kosong, mahasiswa mengajukan Permohonan Peminjaman Ruangan kepada Kalab untuk mendapatkan persetujuan (ACC), dan terakhir melakukan konfirmasi slot ke teknisi[cite: 2].
- **Kurikulum TI OBE 2026:** Untuk Prodi Teknik Informatika, kurikulum memuat 49 mata kuliah dengan total 145 SKS yang tersebar dalam 8 semester[cite: 12]. Mahasiswa akan diarahkan untuk memilih mata kuliah pilihan (stream) mulai Semester 6 yang berbobot 9 SKS[cite: 12].

**B. Penggunaan AI (Prompt Engineering)**
- **Definisi:** Prompt adalah instruksi atau masukan yang diberikan kepada model AI untuk mendapatkan hasil yang spesifik dan relevan[cite: 30]. 
- **Struktur Prompt yang Baik:** Instruksi AI (prompt) yang efektif harus memiliki konteks, yang terdiri dari 4 elemen utama: *Role* (Peran), *Task* (Tugas), *Context* (Konteks), dan *Format*[cite: 31, 32]. 
- **Keuntungan:** Melakukan *prompt engineering* yang baik dapat meningkatkan performa model AI, mengurangi bias atau respon negatif, meningkatkan kontrol, dan memberikan hasil yang lebih dapat diprediksi[cite: 35].

**C. Version Controlling dengan Git & GitHub**
- **Perbedaan Git dan GitHub:** Git adalah *version control system* terdistribusi yang digunakan untuk melacak dan mengelola perubahan kode secara lokal (diciptakan oleh Linus Torvalds pada tahun 2005)[cite: 37, 39]. Sedangkan GitHub adalah platform berbasis web yang digunakan untuk menyimpan repository Git tersebut secara *online* agar mendukung kolaborasi[cite: 39].
- **Alur Kerja Git (Workflow):** Terdiri dari tiga area, yaitu *Working Directory* (salinan proyek yang sedang dikerjakan secara lokal), *Staging Area* (tempat menyimpan informasi perubahan sebelum di-commit), dan *.git directory / Repository* (tempat Git menyimpan metadata dan database utama proyek)[cite: 38].
- **Perintah Esensial Git:** 
  * `git init` (memulai repository baru)[cite: 40].
  * `git add .` (memindahkan file ke *staging area*)[cite: 40].
  * `git commit -m 'message'` (menyimpan file ke Repository)[cite: 40].

### 3. Poin-Poin Penting dan Pengetahuan Baru
- **Sistem Penanganan Pelanggaran Berjenjang:** Sesuai file "Alur penanganan pelanggaran.png", setiap pelanggaran tata tertib memiliki alur penanganan yang terstruktur, dimulai dari teguran dosen secara langsung[cite: 3]. Jika mahasiswa tidak menunjukkan perubahan, dosen akan melaporkan ke Ketua Program Studi (KPS) untuk pembinaan, yang dapat dilanjutkan dengan pemanggilan orang tua/wali mahasiswa hingga berujung pada sanksi[cite: 3].
- **Konsekuensi Akademik (Sanksi):** Pelanggaran terhadap tata tertib (Pasal 16, 17, dan 18) memiliki konsekuensi sanksi yang berjenjang, mulai dari peringatan lisan/tertulis, tidak diperkenankan mengikuti kuliah, tidak diperkenankan mengikuti ujian, hingga sanksi terberat berupa pemberhentian studi (Drop Out) dari Politeknik Negeri Jakarta[cite: 11].
- **Fokus Hilirisasi dan Inkubasi Bisnis:** JTIK tidak hanya berfokus pada pendidikan teori, tetapi pada tahun 2028-2029 menargetkan aktivasi inkubator bisnis dengan minimal 2 prototipe/ide startup dan peningkatan luaran penelitian terapan[cite: 10].
- **Kolaborasi Git ke GitHub via SSH:** Untuk menghubungkan Git lokal dengan GitHub secara aman, otentikasi dapat dilakukan dengan membuat SSH Key menggunakan algoritma ed25519 (`ssh-keygen -t ed25519`) dan menambahkannya ke pengaturan SSH di akun GitHub[cite: 46, 48].
- **Perintah Integrasi *Remote*:** Setelah siap berkolaborasi secara *online*, repository lokal dapat dihubungkan menggunakan `git remote add <name> <url>`, kemudian perubahan kode diunggah menggunakan perintah `git push origin main` dan ditarik/diperbarui dengan perintah `git pull origin main`[cite: 41].
